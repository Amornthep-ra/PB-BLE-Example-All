Custom Board (ESP32 / ESP32-C3)

บอร์ดของคุณไม่อยู่ในรายการ? คู่มือนี้บอกว่าต้องใช้ไฟล์ไหน แก้ตรงไหน และต่อมอเตอร์อย่างไร เพื่อบังคับหุ่นด้วยแอป PB Controller

1ก่อนเริ่ม

  • บอร์ดต้องใช้ชิป ESP32 หรือ ESP32-C3 (PB-BLE ยังไม่รองรับ ESP32-S2/S3, Arduino UNO, Nano, RP2040 ฯลฯ)
  • รู้ว่าบอร์ดหรือหุ่นใช้ชิปไดรเวอร์มอเตอร์รุ่นไหน และมอเตอร์ต่อกับ GPIO ขาไหน (ดูจาก schematic หรือเอกสารของบอร์ด)
  • มือถือที่ติดตั้งแอป PB Controller
ถ้าบอร์ดของคุณมีในรายการ ให้ใช้โฟลเดอร์ของบอร์ดนั้นแทน PicoMini · NKP_ONE · NKP_V2 · ESPRobotV2 เพราะตั้งค่าขามอเตอร์ไว้ให้แล้ว

2ติดตั้งโปรแกรมและ Lib

  1. ติดตั้ง Arduino IDE 2.x
  2. ติดตั้งบอร์ด esp32 by Espressif Systems เวอร์ชัน 3.3.11 ผ่าน Tools › Board › Boards Manager…
  3. ดาวน์โหลด Lib PB-BLE.zip แล้วติดตั้งด้วย Sketch › Include Library › Add .ZIP Library…
  4. ดาวน์โหลด โค้ดตัวอย่าง (.zip) แล้วแตกไฟล์
ห้ามใช้ esp32 core เวอร์ชัน 4.xจะ compile ไม่ผ่าน (BLEDevice.h: No such file or directory)

ขั้นตอนพร้อมรูปแบบละเอียด ดูได้ในคู่มือ PicoMini ขั้นตอนที่ 2–4 (ทำเหมือนกันทุกบอร์ด)

3ไฟล์ที่ต้องใช้

หลังแตก zip ให้เข้าโฟลเดอร์ Custom_Board เลือกโปรแกรมตามโหมดที่จะใช้ในแอป

PB-BLE-Example-All-main/ └── Custom_Board/ ← ใช้โฟลเดอร์นี้ ├── PB_4BTN_Control/ │ ├── PB_4BTN_Control.ino ← โหมด 4BTN (Lo / Med / Hi) │ └── PB_Board.h ← ★ ตั้งค่ามอเตอร์ของบอร์ดคุณ ├── PB_8BTN_Control/ │ ├── PB_8BTN_Control.ino ← โหมด 8BTN (DRV / TRN) │ └── PB_Board.h └── PB_Joystick_Control/ ├── PB_Joystick_Control.ino ← โหมด Joystick (6 แบบ) └── PB_Board.h
ไฟล์แก้อะไร
PB_Board.hชนิดไดรเวอร์มอเตอร์, หมายเลขขา GPIO, 2WD/4WD, กลับทิศล้อ (ไฟล์เดียวที่ต้องแก้ให้ตรงกับบอร์ด)
.inoชื่อ BLE / Board ID / Pair Code และค่าความเร็ว เหมือนบอร์ดอื่น ๆ
แต่ละโฟลเดอร์มี PB_Board.h ของตัวเอง ให้แก้ไฟล์ในโฟลเดอร์ที่ใช้งาน ถ้าจะใช้หลายโหมด แก้ไฟล์แรกให้เสร็จแล้ว copy ไปทับในอีก 2 โฟลเดอร์ได้เลย ไฟล์นี้ต้องอยู่คู่กับ .ino เสมอ

ใน Arduino IDE จะเห็น PB_Board.h เป็นแท็บที่ 2 ข้างไฟล์ .ino คลิกแท็บนั้นเพื่อแก้ได้เลย

4ดูชนิดไดรเวอร์มอเตอร์

ดูชื่อชิปบนบอร์ดหรือโมดูลไดรเวอร์ แล้วเลือกแบบที่ตรงกันจากตารางนี้

MOTOR_DRIVERขาต่อมอเตอร์ 1 ตัวชิป / โมดูลที่พบบ่อย
1 DRIVER_IN1_IN22 ขา PWM: IN1, IN2DRV8833, L9110S, MX1508, TB6612 (ต่อ PWM ที่ IN1/IN2 และต่อ PWMA เป็น HIGH)
2 DRIVER_DIR_PWM1 ขาทิศ + 1 ขา PWM: DIR (PH), PWM (EN)DRV8835 (โหมด PH/EN), บอร์ดหุ่นยนต์หลายรุ่น เช่น PicoMini
3 DRIVER_IN1_IN2_EN2 ขาทิศ + 1 ขา PWM: IN1, IN2, ENL298N (IN1, IN2, ENA), TB6612FNG (AIN1, AIN2, PWMA)

5ใส่หมายเลขขาใน PB_Board.h

เปิดแท็บ PB_Board.h แก้ 2 ส่วนนี้ ใส่เลข GPIO แทน -1

#define MOTOR_DRIVER  DRIVER_IN1_IN2   // <-- choose 1, 2 or 3

const int LEFT_PINS[3]   = { -1, -1, -1 };   // left motor
const int RIGHT_PINS[3]  = { -1, -1, -1 };   // right motor

ตัวอย่างตามชนิดไดรเวอร์

แบบ 1: DRV8833 / L9110S

#define MOTOR_DRIVER DRIVER_IN1_IN2
//                           IN1 IN2  -
const int LEFT_PINS[3]  = { 25, 26, -1 };
const int RIGHT_PINS[3] = { 27, 14, -1 };

แบบ 2: DIR + PWM

#define MOTOR_DRIVER DRIVER_DIR_PWM
//                           DIR PWM  -
const int LEFT_PINS[3]  = { 21, 20, -1 };
const int RIGHT_PINS[3] = { 10, 8,  -1 };

แบบ 3: L298N

#define MOTOR_DRIVER DRIVER_IN1_IN2_EN
//                           IN1 IN2 ENA
const int LEFT_PINS[3]  = { 27, 26, 14 };
const int RIGHT_PINS[3] = { 25, 33, 32 };

แบบ 3: TB6612FNG

#define MOTOR_DRIVER DRIVER_IN1_IN2_EN
//                           AIN1 AIN2 PWMA
const int LEFT_PINS[3]  = { 27, 26, 14 };
const int RIGHT_PINS[3] = { 25, 33, 32 };
const int DRIVER_ENABLE_PIN = 13;  // STBY

ตัวเลขในตัวอย่างเป็นแค่ตัวอย่างเท่านั้น ให้ใช้เลขขาที่ต่อจริงบนบอร์ดของคุณ

ค่าอื่นใน PB_Board.hใช้เมื่อไร
DRIVER_ENABLE_PINไดรเวอร์มีขาที่ต้องตั้งเป็น HIGH ถึงจะทำงาน เช่น STBY ของ TB6612 หรือขา Enable ของบอร์ด ถ้าไม่มีให้ใส่ -1
INVERT_LEFT / INVERT_RIGHTล้อฝั่งนั้นหมุนกลับทิศ ให้ตั้งเป็น true (ดูขั้นตอนที่ 7)
PWM_FREQค่าเริ่ม 1000 Hz ถ้ามอเตอร์มีเสียงหวีด ลองตั้ง 5000 หรือ 20000
ขาที่ไม่ควรใช้ ESP32: GPIO 6–11 (ต่อกับหน่วยความจำ), 34–39 (รับสัญญาณเข้าได้อย่างเดียว), ระวังขา 0, 2, 12, 15 (มีผลตอนบูต)
ESP32-C3: GPIO 12–17 (หน่วยความจำในโมดูลส่วนใหญ่), 18–19 (USB), ระวังขา 2, 8, 9 (มีผลตอนบูต)

62WD / 4WD

หุ่นแบบตั้งค่า
2WD มอเตอร์ 2 ตัว#define DRIVE_TYPE 2 ใส่ขาแค่ LEFT_PINS, RIGHT_PINS
4WD ไดรเวอร์แยก 4 ช่อง#define DRIVE_TYPE 4 ใส่ขาเพิ่มใน LEFT2_PINS (หลังซ้าย), RIGHT2_PINS (หลังขวา) ล้อฝั่งเดียวกันจะหมุนพร้อมกัน
ESP32-C3 มี PWM แค่ 6 ช่อง ถ้าเป็นแบบ 1 แล้วต่อ 4WD (ต้องใช้ 8 ช่อง) จะไม่พอ ให้ใช้แบบ 2 หรือ 3 หรือต่อมอเตอร์ขนานกันแทน
4WD แต่มอเตอร์ 2 ตัวต่อขนานกันในช่องเดียวใช้ DRIVE_TYPE 2 เพราะในโค้ดเห็นเป็นแค่ 2 ช่อง

7อัปโหลดและทดสอบทิศทาง

  1. แก้ชื่อ BLE / Board ID / Pair Code ใน .ino (กติกาเดียวกับคู่มือ PicoMini ขั้นตอนที่ 6)
  2. เลือกบอร์ดใน Tools › Board ให้ตรงกับชิป เช่น ESP32 Dev Module หรือ ESP32C3 Dev Module แล้วเลือก Port
  3. ตั้ง Tools › Partition Scheme เป็น Huge APP (โค้ด Bluetooth มักใหญ่เกินค่าเริ่มต้น)
  4. ถ้าเป็น ESP32-C3 ที่เสียบ USB เข้าชิปโดยตรง ให้ตั้ง USB CDC On Boot เป็น Enabled
  5. กด Upload แล้วเปิด Serial Monitor ที่ 115200 จะเห็นข้อความ [PB_Board] driver type 1, 2WD
ถ้าเห็น “WARNING: motor pins are not set”แปลว่ายังไม่ได้ใส่ขาใน PB_Board.h หรือใส่ไม่ครบ มอเตอร์จะไม่หมุน (ตั้งใจให้เป็นแบบนี้ เพื่อกันไม่ให้โค้ดไปสั่งขาที่ไม่รู้จัก)
ยกล้อหุ่นให้ลอยก่อนทดสอบเชื่อมแอป เลือกโหมด 8BTN แล้วกด Start ลองกดปุ่มทีละปุ่ม แล้วแก้ตามตารางนี้
อาการเมื่อกดวิธีแก้ใน PB_Board.h
UP แล้วล้อซ้ายหมุนถอยหลังINVERT_LEFT = true
UP แล้วล้อขวาหมุนถอยหลังINVERT_RIGHT = true
UP แล้วถอยหลังทั้งคู่ตั้ง true ทั้งสองค่า
LEFT แล้วหุ่นหมุนไปทางขวาสลับค่าใน LEFT_PINS กับ RIGHT_PINS
4WD: ล้อหลังหมุนสวนกับล้อหน้าสลับลำดับ 2 ขาแรกใน LEFT2_PINS / RIGHT2_PINS ของล้อนั้น หรือสลับสายมอเตอร์

8ปรับความเร็วและใช้งานแอป

ส่วนนี้เหมือนบอร์ดอื่นทุกอย่าง เพราะไฟล์ .ino เป็นตัวเดียวกัน

  • ปรับความเร็ว 4BTN / 8BTN / Joystick (DEADZONE, TURN_MAX, JOY_MODE ฯลฯ): ดูคู่มือ PicoMini ขั้นตอนที่ 7
  • เชื่อมต่อแอปและทดสอบ: ดูคู่มือ PicoMini ขั้นตอนที่ 9

9ขั้นสูง: ไดรเวอร์แบบอื่น

ถ้าบอร์ดสั่งมอเตอร์แบบที่ไม่อยู่ในตาราง เช่น ผ่านชิป I2C หรือใช้ Lib ของบอร์ดเอง ให้แก้ 3 ฟังก์ชันท้ายไฟล์ PB_Board.h ได้โดยตรง โดยไม่ต้องแก้ .ino

void boardMotorInit()               { /* ตั้งค่าขา / เริ่ม Lib มอเตอร์ */ }
void boardSetMotors(int left, int right) { /* สั่งฝั่งซ้าย/ขวา -100..100 */ }
void boardFailsafeStop()            { /* หยุดมอเตอร์ (ถูกเรียกจาก BLE task) */ }
กติกาของ boardFailsafeStop() ฟังก์ชันนี้ทำงานใน task ของ Bluetooth ตอนหลุดการเชื่อมต่อ ให้เขียนสั้น ๆ ห้ามใช้ delay, Serial, I2C หรือคำสั่ง BLE ถ้ามอเตอร์สั่งผ่าน I2C ให้ตั้ง flag ไว้แทน แล้วให้ loop() เป็นตัวสั่งหยุด

ดูตัวอย่างของจริงได้จากโฟลเดอร์บอร์ดอื่น:

ตัวอย่างรูปแบบ
NKP_V2มอเตอร์ผ่าน I2C ตอนหยุดฉุกเฉินใช้ flag ให้ loop() สั่งหยุด และส่งคำสั่งซ้ำทุก 100 ms
ESPRobotV2PWM 4 มอเตอร์ เลือก 2WD / 4WD
PicoMiniDIR + PWM และมีขา Enable ของไดรเวอร์

10แก้ปัญหาที่พบบ่อย

เชื่อมแอปได้ แต่มอเตอร์ไม่หมุนเลย ดู Serial Monitor ว่ามีคำเตือนเรื่องขาไหม เลือก MOTOR_DRIVER ถูกแบบไหม ใส่ DRIVER_ENABLE_PIN แล้วหรือยัง (TB6612 ต้องตั้ง STBY เป็น HIGH) ต่อ GND ร่วมกันหรือยัง และเปิดไฟมอเตอร์แล้วหรือยัง
มอเตอร์หมุนทางเดียว กลับทิศไม่ได้ น่าจะเลือก MOTOR_DRIVER ผิดแบบ หรือลำดับขาในวงเล็บผิด ให้ดูตารางในขั้นตอนที่ 4
มอเตอร์หมุนเองตอนเปิดเครื่อง ขาที่ใช้อาจเป็นขาที่มีผลตอนบูต (strapping pin) ให้ย้ายไปขาอื่น (ดูขั้นตอนที่ 5)
ESP32-C3: หลังเชื่อม Bluetooth แล้วมอเตอร์ไม่ทำงาน โค้ดเรียก boardMotorInit() ซ้ำหลังเริ่ม BLE ไว้ให้แล้ว ถ้ายังไม่ทำงาน ให้ตรวจว่าใช้ขา PWM เกินจำนวนช่องที่ชิปมีหรือไม่ (ESP32-C3 มี PWM 6 ช่อง)
BLEDevice.h: No such file or directory ใช้ esp32 core 4.x อยู่ ให้เปลี่ยนเป็น 3.3.11
PB_Board.h: No such file or directory ไฟล์ PB_Board.h ไม่ได้อยู่ในโฟลเดอร์เดียวกับ .ino
