บอร์ด NKP_V2 (ESP32)

1เตรียมอุปกรณ์

  • คอมพิวเตอร์ Windows / macOS / Linux ที่ต่ออินเทอร์เน็ตได้
  • บอร์ด NKP_V2 (ESP32) พร้อมมอเตอร์ซ้าย (M1) – ขวา (M2) และแบตเตอรี่ (บอร์ดสั่งมอเตอร์ผ่านชิปควบคุมบนบอร์ดทาง I2C)
  • สาย USB ที่ส่งข้อมูลได้ (สายชาร์จอย่างเดียวจะมองไม่เห็นบอร์ด)
  • มือถือที่ติดตั้งแอป PB Controller และเปิด Bluetooth

2ติดตั้ง Arduino IDE

  1. เข้าเว็บ arduino.cc/en/software
  2. ดาวน์โหลด Arduino IDE 2.x ตามระบบปฏิบัติการของเครื่อง แล้วติดตั้งตามขั้นตอนปกติ
  3. ถ้าโปรแกรมถามให้ติดตั้ง Driver (USB / Serial) ให้กด Install ทุกตัว

3ติดตั้งบอร์ด ESP32 (Core)

3.1 เพิ่มลิงก์บอร์ด ESP32

  1. เปิด File › Preferences… (macOS: Arduino IDE › Settings…)
  2. ในช่อง Additional boards manager URLs วางลิงก์นี้ แล้วกด OK
https://espressif.github.io/arduino-esp32/package_esp32_index.json

ถ้าในช่องมีลิงก์อื่นอยู่แล้ว ให้กดไอคอนข้างช่องแล้วเพิ่มลิงก์นี้เป็นบรรทัดใหม่

3.2 ติดตั้ง esp32 เวอร์ชัน 3.3.11

  1. เปิด Tools › Board › Boards Manager… (หรือกดไอคอนบอร์ดที่แถบซ้าย)
  2. ค้นหา esp32 แล้วหาตัวที่ชื่อ esp32 by Espressif Systems
  3. ที่ช่องเลือกเวอร์ชัน เลือก 3.3.11 แล้วกด Install รอจนเสร็จ (ใช้เวลาหลายนาที)
ห้ามใช้ esp32 เวอร์ชัน 4.x Core 4.0.0 ขึ้นไปเปลี่ยนระบบ Bluetooth ใหม่ทั้งหมด ถ้าใช้จะ compile ไม่ผ่านและขึ้นข้อความ BLEDevice.h: No such file or directory ถ้าเผลอติดตั้งไปแล้ว ให้กลับไปที่ Boards Manager แล้วเลือกเวอร์ชัน 3.3.11 กด Install ทับได้เลย

4ติดตั้ง Lib PB-BLE

  1. เข้าหน้าดาวน์โหลดล่าสุด: github.com/Amornthep-ra/PB-BLE/releases/latest
  2. เลื่อนลงไปหัวข้อ Assets แล้วดาวน์โหลดไฟล์ PB-BLE.zip (ไม่ต้องแตกไฟล์)
  3. ใน Arduino IDE เปิด Sketch › Include Library › Add .ZIP Library…
  4. เลือกไฟล์ PB-BLE.zip ที่ดาวน์โหลดมา รอจนมีข้อความ Library installed
  5. ตรวจสอบ: เปิด File › Examples ต้องเห็นหมวด PB-BLE
อย่าติดตั้ง Lib BLE ตัวอื่นเพิ่ม PB-BLE ใช้ Bluetooth ที่มากับบอร์ด ESP32 อยู่แล้ว ไม่ต้องลง “ESP32 BLE Arduino” แยก

5ดาวน์โหลดโค้ดตัวอย่าง

ดาวน์โหลดโค้ดตัวอย่างทั้งหมด
⬇ PB-BLE-Example-All.zip
หรือเข้า github.com/Amornthep-ra/PB-BLE-Example-All แล้วกดปุ่มเขียว Code › Download ZIP
  1. กดลิงก์ด้านบนเพื่อดาวน์โหลดไฟล์ zip
  2. แตกไฟล์ zip ก่อน (Windows: คลิกขวาที่ไฟล์ แล้วเลือก Extract All…) แล้ววางไว้ในที่ที่หาง่าย เช่น Desktop หรือ Documents/Arduino
ห้ามเปิดไฟล์ .ino จากในไฟล์ zip โดยตรงถ้าไม่แตกไฟล์ก่อน Arduino IDE จะหา NKP_V2Motor_drive.h ไม่เจอ และจะบันทึกค่าที่แก้ไม่ได้

ไฟล์ zip รวมตัวอย่างของหลายบอร์ดไว้ด้วยกัน ให้เข้าโฟลเดอร์ NKP_V2 ในนั้นมี 3 โปรแกรม เลือกตามโหมดที่จะใช้บังคับในแอป

PB-BLE-Example-All-main/ └── NKP_V2/ ← ใช้โฟลเดอร์นี้ ├── PB_4BTN_Control/ │ ├── PB_4BTN_Control.ino ← บังคับด้วยปุ่มลูกศร + ปุ่ม Lo/Med/Hi (โหมด 4BTN) │ └── NKP_V2Motor_drive.h ├── PB_8BTN_Control/ │ ├── PB_8BTN_Control.ino ← บังคับด้วยปุ่มลูกศร (โหมด 8BTN) │ └── NKP_V2Motor_drive.h ← ไฟล์สั่งมอเตอร์ของบอร์ด (ห้ามลบ) └── PB_Joystick_Control/ ├── PB_Joystick_Control.ino ← บังคับด้วยจอย เลือกได้ 6 แบบ (โหมด Joystick) └── NKP_V2Motor_drive.h
  1. เปิดไฟล์ .ino ที่ต้องการด้วย Arduino IDE (ดับเบิลคลิก หรือ File › Open…)
  2. ด้านบนต้องเห็นแท็บ 2 แท็บ คือ .ino และ NKP_V2Motor_drive.h
ข้อควรระวัง ชื่อโฟลเดอร์ต้องตรงกับชื่อไฟล์ .ino และต้องมี NKP_V2Motor_drive.h อยู่ในโฟลเดอร์เดียวกัน ห้ามย้ายไฟล์ .ino ออกมาอยู่ตัวเดียว

6ตั้งชื่อและรหัสบอร์ด

ด้านบนของไฟล์ .ino จะมี 3 บรรทัดนี้ แต่ละคนต้องตั้งไม่ให้ซ้ำกัน ไม่อย่างนั้นมือถือจะเชื่อมผิดตัว

const char *BLE_NAME  = "PB-NKPV201";     // ชื่อที่เห็นในแอป
const char *BOARD_ID  = "NKPV201";        // รหัสบอร์ด
const char *PAIR_CODE = "12345678";       // รหัสจับคู่ที่ต้องกรอกในแอป
ค่ากติกาตัวอย่าง
BLE_NAMEชื่อที่จะแสดงในแอป ห้ามเว้นว่างPB-Team05
BOARD_IDภาษาอังกฤษ/ตัวเลข 1–32 ตัว ไม่มีเว้นวรรคหรือสัญลักษณ์ ห้ามซ้ำกับบอร์ดอื่นTeam05
PAIR_CODEภาษาอังกฤษ/ตัวเลข 8–16 ตัว ไม่มีเว้นวรรคหรือสัญลักษณ์ (ตัวเล็ก/ใหญ่ถือว่าเหมือนกัน)Robot2026
ห้ามใช้ - _ หรือช่องว่างใน BOARD_ID และ PAIR_CODEถ้าใส่ผิดกติกา บอร์ดจะเชื่อมต่อแอปไม่ได้ (ใน BLE_NAME ใช้ - ได้)

7ปรับความเร็ว

ความเร็วมอเตอร์ทั้งหมดใช้สเกล 0–100 โดย 100 คือแรงสุด ค่าติดลบคือหมุนถอยหลัง

7.1 โหมด 4BTN (ไฟล์ PB_4BTN_Control.ino)

กดปุ่ม Lo / Med / Hi ในแอปเพื่อเปลี่ยนระดับความเร็ว ระดับที่เลือกจะค้างไว้จนกว่าจะกดระดับอื่น ตอนเปิดเครื่องจะเริ่มที่ Lo

ความเร็วของแต่ละระดับแก้ได้ที่ด้านบนของไฟล์

//                          Lo   Med  Hi
const int DRIVE_SPEED[3] = { 30,  60, 100 };  // forward / backward
const int TURN_SPEED[3]  = { 25,  35,  50 };  // spin + how tight curves are
ค่าความหมายปรับอย่างไร
DRIVE_SPEEDความเร็วเดินหน้า/ถอยหลังของระดับ Lo, Med, Hi ตามลำดับหุ่นวิ่งเร็วจนคุมไม่อยู่ → ลดตัวเลข
TURN_SPEEDความเร็วหมุนตัว และความแคบของโค้ง (ใช้หลักเดียวกับ TRN ในหัวข้อ 7.2)หมุนไวเกิน → ลด
โค้งกว้างเกิน → เพิ่ม

7.2 โหมด 8BTN (ไฟล์ PB_8BTN_Control.ino)

โหมดนี้ไม่ต้องแก้โค้ด ปรับความเร็วได้จากแถบเลื่อนในแอปเลย

DRV

ความเร็วเดินหน้า / ถอยหลัง

TRN

ความเร็วหมุนตัว และความแคบของโค้ง (ค่ายิ่งมาก โค้งยิ่งแคบ)
การเคลื่อนที่ล้อซ้ายล้อขวา
เดินหน้า / ถอยหลัง±DRV±DRV
หมุนซ้ายอยู่กับที่−TRN+TRN
โค้งซ้ายไปหน้าDRV − TRN (ล้อใน)DRV (ล้อนอก)
ตัวอย่างตั้ง DRV = 80, TRN = 30 แล้วกด UP+LEFT: ล้อซ้ายวิ่ง 50 ล้อขวาวิ่ง 80 หุ่นจะโค้งซ้ายกว้าง ๆ ถ้าตั้ง TRN ≥ DRV ล้อในจะหยุด และหุ่นจะโค้งแคบที่สุด

7.3 โหมด Joystick (ไฟล์ PB_Joystick_Control.ino)

ขั้นที่ 1: เลือกรูปแบบการบังคับ แก้ตัวเลขหรือชื่อในบรรทัดนี้ แล้วอัปโหลดใหม่

#define JOY_MODE  ARCADE_DUAL   // <-- choose 1..6 (or the name)
JOY_MODEจอยซ้ายจอยขวาเหมาะกับ
1 ARCADE_DUAL
ค่าเริ่มต้น		ขึ้น–ลง = เดินหน้า/ถอยซ้าย–ขวา = เลี้ยวใช้ทั่วไป บังคับง่ายที่สุด
2 ARCADE_DUAL_SWAPซ้าย–ขวา = เลี้ยวขึ้น–ลง = เดินหน้า/ถอยคนถนัดซ้าย
3 ARCADE_LEFTขึ้น–ลง = เดินหน้า/ถอย
ซ้าย–ขวา = เลี้ยว		ไม่ใช้บังคับด้วยมือซ้ายมือเดียว
4 ARCADE_RIGHTไม่ใช้ขึ้น–ลง = เดินหน้า/ถอย
ซ้าย–ขวา = เลี้ยว		บังคับด้วยมือขวามือเดียว
5 TANKขึ้น–ลง = ล้อซ้ายขึ้น–ลง = ล้อขวาแบบรถถัง คุมล้อทีละข้างได้แม่น
6 CARขึ้น–ลง = คันเร่งซ้าย–ขวา = พวงมาลัยแบบรถจริง ต้องเร่งก่อนถึงจะเลี้ยวได้ และหมุนอยู่กับที่ไม่ได้

รูปด้านล่างคือแบบ 1 (ARCADE_DUAL)

ขั้นที่ 2: ปรับค่า ค่าอยู่ด้านบนของไฟล์ แก้ตัวเลขแล้วอัปโหลดใหม่

const int DEADZONE  = 15;   // stick center zone ignored; speed starts from 0 after it
const int MAX_SPEED = 100;  // cap for every wheel (lower = slower robot)
const int TURN_MAX  = 25;   // modes 1-4: turn amount at full stick
const int CAR_STEER = 70;   // mode 6: how much the inner wheel slows at full steering (%)
ค่าความหมายปรับอย่างไร
DEADZONE
ค่าเริ่ม 15		 ระยะตรงกลางจอยที่ไม่นับว่าดัน กันหุ่นไหลเองตอนปล่อยมือ เมื่อดันพ้นระยะนี้ ความเร็วจะเริ่มจาก 0 หุ่นขยับเองตอนปล่อยจอย → เพิ่ม (เช่น 20)
ต้องดันลึกกว่าจะเริ่มวิ่ง → ลด (เช่น 10)
MAX_SPEED
ค่าเริ่ม 100
ทุกแบบ		 เพดานความเร็วของทุกล้อ ดันจอยสุดก็ไม่เกินค่านี้ ผู้เริ่มต้นหรือสนามเล็ก → ลด (เช่น 60)
TURN_MAX
ค่าเริ่ม 25
แบบ 1–4		 แรงเลี้ยวสูงสุดเมื่อดันจอยแกนเลี้ยวจนสุด (0–100) เลี้ยวไวเกิน / หมุนคว้าง → ลด (เช่น 15)
เลี้ยวช้า / โค้งกว้างเกิน → เพิ่ม (เช่น 40)
CAR_STEER
ค่าเริ่ม 70
แบบ 6		 ล้อด้านในจะช้าลงกี่ % เมื่อหมุนพวงมาลัยจนสุด (100 = ล้อในหยุด) โค้งกว้างเกิน → เพิ่ม
เลี้ยวแรงเกิน → ลด
ความเร็วตรงและความเร็วเลี้ยวรวมกันอย่างไร (แบบ 1–4)ล้อซ้าย = เดินหน้า + เลี้ยว และล้อขวา = เดินหน้า − เลี้ยว ถ้าข้างไหนเกิน 100 โปรแกรมจะลดทั้งสองข้างตามสัดส่วนเดียวกันให้เอง ส่วนแบบ 5 TANK ไม่ใช้ TURN_MAX เพราะจอยแต่ละข้างคุมล้อโดยตรง
เช็กว่าอัปโหลดแบบที่ถูกแล้วเปิด Serial Monitor (115200) แล้วกดรีเซ็ตบอร์ด จะขึ้นข้อความ Joystick mode: 1 (ARCADE_DUAL)

7.4 ถ้าล้อหมุนผิดทาง (ใช้ได้ทุกไฟล์)

หาฟังก์ชัน drive() ในไฟล์ แล้วใส่เครื่องหมายลบหน้าค่าของล้อที่หมุนกลับด้าน

void drive(int left, int right) {
  ...
  motor(1, -left);   // ล้อซ้ายหมุนกลับด้าน → ใส่ - หน้า left
  motor(2, right);   // ล้อขวา
  ...
}

ถ้ากดเลี้ยวซ้ายแล้วหุ่นไปทางขวา แสดงว่าสายมอเตอร์ซ้าย–ขวาสลับกัน ให้สลับเลข motor(1, …) กับ motor(2, …)

8เลือกบอร์ดและอัปโหลด

  1. เสียบสาย USB เข้าบอร์ด NKP_V2
  2. Tools › Board › esp32 › ESP32 Dev Module
  3. Tools › Port เลือกพอร์ตของบอร์ด (Windows จะเป็น COMx ส่วน macOS จะเป็น /dev/cu.usbserial… หรือ /dev/cu.wchusbserial…)
  4. ตั้งค่าเมนู Tools ตามตารางนี้
เมนู Toolsค่าที่ตั้ง
Partition SchemeHuge APP (3MB No OTA/1MB SPIFFS) (โค้ด Bluetooth บน ESP32 มักใหญ่เกินค่าเริ่มต้น จนขึ้น Sketch too big)
อื่น ๆใช้ค่าเดิม
  1. กดปุ่ม ✓ Verify ก่อน เพื่อตรวจว่า compile ผ่าน
  2. กดปุ่ม → Upload รอจนขึ้นข้อความ Hard resetting via RTS pin... แสดงว่าเสร็จแล้ว
ถ้าขึ้น “Failed to connect” หรือหาพอร์ตไม่เจอ ตรวจว่าเลือกพอร์ตถูก และติดตั้งไดรเวอร์ USB-Serial แล้ว (CH340 หรือ CP210x ขึ้นกับชิปบนบอร์ด) ถ้ายังไม่ได้ ให้กด Upload แล้วกดปุ่ม BOOT บนโมดูล ESP32 ค้างไว้ ตอนที่ขึ้นข้อความ Connecting.... จนเริ่มอัปโหลด แล้วจึงปล่อย

9เชื่อมต่อแอปและทดสอบ

ยกล้อหุ่นให้ลอยก่อนทดสอบครั้งแรกป้องกันหุ่นวิ่งตกโต๊ะถ้าทิศทางมอเตอร์ยังไม่ถูกต้อง
  1. เปิดสวิตช์แบตเตอรี่ของหุ่น
  2. เปิดแอป PB Controller แล้วเลือกเชื่อมต่อ BLE ชื่อตาม BLE_NAME ที่ตั้งไว้
  3. กรอก Pair Code ให้ตรงกับ PAIR_CODE ในโค้ด
  4. เลือกโหมดให้ตรงกับโค้ดที่อัปโหลด: 4BTN, 8BTN หรือ Joystick
  5. กด Start แล้วลองกดปุ่มหรือดันจอย
ระบบหยุดอัตโนมัติถ้าหลุดการเชื่อมต่อ ยังไม่กด Start หรือแอปไม่ส่งข้อมูลเกิน 0.4 วินาที มอเตอร์จะหยุดเองทันที

ถ้าต้องการดูสถานะ เปิด Tools › Serial Monitor แล้วตั้งความเร็วเป็น 115200 baud

NKP_V2Motor_drive.h: No such file or directory ไฟล์ NKP_V2Motor_drive.h ไม่ได้อยู่ในโฟลเดอร์เดียวกับ .ino ให้ตรวจโครงสร้างโฟลเดอร์ในขั้นตอนที่ 5
PBGamepad.h: No such file or directory ยังไม่ได้ติดตั้ง Lib PB-BLE ให้ทำขั้นตอนที่ 4 แล้วปิดและเปิด Arduino IDE ใหม่
Compile ไม่ผ่าน เพราะมีไฟล์ PBGamepad.h / .cpp ซ้ำ ลบไฟล์ PBGamepad.* และ PBJoystick.* รุ่นเก่าที่คัดลอกไว้ข้างไฟล์ .ino ออก ให้เหลือแค่ตัวที่ติดตั้งเป็น Lib
ไม่มีพอร์ตให้เลือกใน Tools › Port ลองเปลี่ยนสาย USB เพราะบางเส้นชาร์จได้อย่างเดียว เปลี่ยนช่อง USB และติดตั้งไดรเวอร์ CH340 / CP210x (ดูขั้นตอนที่ 8)
ในแอปไม่เจอชื่อบอร์ด ตรวจว่าเปิด Bluetooth และ Location (Android) และให้สิทธิ์แอปแล้ว ตรวจว่าไม่มีมือถือเครื่องอื่นเชื่อมบอร์ดค้างอยู่ จากนั้นกดรีเซ็ตบอร์ดหรือถอดสายเสียบใหม่
Pair Code ไม่ผ่าน ตรวจว่า PAIR_CODE ในโค้ดที่อัปโหลดล่าสุดตรงกับที่กรอก ยาว 8–16 ตัว และไม่มีสัญลักษณ์ ถ้าเพิ่งเปลี่ยนรหัส ให้ลบอุปกรณ์เก่าในแอปแล้วจับคู่ใหม่
เชื่อมต่อแล้วแต่หุ่นไม่วิ่ง ตรวจว่ากด Start ในแอปแล้ว เลือกโหมดตรงกับโค้ด (4BTN / 8BTN / Joystick) และเปิดแบตเตอรี่แล้ว ในโหมด 8BTN ให้ดูด้วยว่าแถบ DRV / TRN ไม่ได้อยู่ที่ 0 ส่วนโหมด Joystick แบบ CAR ต้องดันคันเร่งก่อน หุ่นถึงจะเลี้ยวได้
Joystick บังคับแล้วไม่เหมือนที่คิด ตรวจค่า JOY_MODE ในไฟล์ (ดูขั้นตอนที่ 7.3) เช่น แบบ TANK ต้องดันจอยทั้งสองข้างขึ้นพร้อมกันถึงจะเดินหน้าตรง
หุ่นขยับเองตอนปล่อยจอย เพิ่มค่า DEADZONE (ดูขั้นตอนที่ 7.2)
