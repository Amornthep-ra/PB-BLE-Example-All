PB-BLE Examples

ตัวอย่างโค้ด Arduino สำหรับบังคับหุ่นยนต์ด้วยแอป PB Controller ผ่าน Bluetooth แยกตามบอร์ด เลือกบอร์ดที่ใช้แล้วเปิดคู่มือของบอร์ดนั้น

⬇ ดาวน์โหลดโค้ดทั้งหมด (.zip) GitHub Lib PB-BLE

เลือกบอร์ด

PicoMini

ESP32-C3 · 2WD

หุ่นยนต์ 2 ล้อ บังคับผ่านแอป PB Controller

  • 4BTN: ปุ่มลูกศร + ระดับความเร็ว Lo / Med / Hi
  • 8BTN: ปุ่ม 8 ทิศ ปรับความเร็วด้วย DRV / TRN
  • Joystick: เลือกได้ 6 แบบ (Arcade, Tank, Car ฯลฯ)
📖 เปิดคู่มือ ดูโค้ด

NKP_V2

ESP32 · 2WD / 4WD

หุ่นยนต์ 2WD หรือ 4WD (เลือกด้วย DRIVE_TYPE) สั่งมอเตอร์ผ่าน I2C บังคับผ่านแอป PB Controller

  • 4BTN: ปุ่มลูกศร + ระดับความเร็ว Lo / Med / Hi
  • 8BTN: ปุ่ม 8 ทิศ ปรับความเร็วด้วย DRV / TRN
  • Joystick: เลือกได้ 6 แบบ (Arcade, Tank, Car ฯลฯ)

ESPRobotV2

ESP32 · 2WD / 4WD

หุ่นยนต์ 2WD หรือ 4WD (เลือกด้วย DRIVE_TYPE) มอเตอร์ 4 ช่อง บังคับผ่านแอป PB Controller
